## 子问题对应速记（三道题通用模板）

真题子问题三件套，写死对应段落，任何一题都能套：

| 子问题类型 | 固定落点 | 内容要点 |
|-----------|---------|---------|
| ① 项目与你的工作 | P1 项目概述 + 摘要 | 取 §2 统一概述 180 字，不改 |
| ② 概念/方法论内涵 | P2 概念段 | **原样照抄考题标题核心术语**写进加粗小标题 |
| ③ 设计/遇问题/如何解决 | P3 核心设计 + P4 关键问题 | P3 放选型对比，P4 放 2 条五段式案例 |

**P4 万能展开**（每道题固定写 2 条，从案例列取色）：
```
问题现象 → 产生原因 → 备选方案对比（=放弃方案列） → 最终落地方案 → 达到效果(=P5/§6指标)
```

## Lambda / Kappa 双口径备忘（防"数字/口径打架"致命错）

- **题目6 用 Lambda**（Flink 实时 + Spark 离线 + TDengine），**题目11 用 Kappa**（Flink 单引擎统一处理）——两者不矛盾，是"不同数据域"的不同选择（环保强溯源的批量域走 Lambda；报警/设备状态等纯流域走 Kappa）。
- 写单篇时**只保留一种说法**；两篇里"本项目数据域划分"的描述必须一致，否则即"口径打架"，直接降档。
