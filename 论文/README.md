## 🎯 论文一句话定位

论文考察你**把真实项目经历，转化为结构化、有论据、体现架构权衡的技术叙述**的能力——不是背范文，而是"我有项目、我做了决策、我讲得清楚"。

---

## 🧩 论文通用结构（骨架）

| 部分 | 字数 | 内容 | 取用来源 |
|------|------|------|----------|
| 1. 摘要 | 约 300 字 | 项目背景 + 你的角色 + 核心技术/架构 + 主要成果 | 素材库 §8 填空模板 |
| 2. 项目概述 | 180~300 字 | 项目规模、业务背景、你的职责、技术选型理由 | 素材库 §2 / §3 |
| 3. 总体架构描述 | 约 200 字 | 文字描述分层拓扑（**机考不要画图**） | 素材库 §4 |
| 4. 核心正文 | 约 1500 字 | 紧扣论题分 3~4 节展开：问题 → 方案对比 → 论证 → 权衡 | 各梯队提纲 |
| 5. 关键问题与解决方案 | 约 400 字 | 2 个真实难题，五段式展开（高分核心，不可省） | 素材库 §7 案例库 |
| 6. 总结 | 约 200 字 | 成效（量化）、不足与改进 | 素材库 §9 |

## 🚀 使用顺序（建议）

1. 先读 [论文章节.md](./论文章节.md) 建立整体认知（考什么、怎么考、时间怎么分）
2. 通读并**背熟** [03-项目背景素材库.md](./03-项目背景素材库.md)：项目参数、量化指标、8 条通用案例、摘要模板
3. 按 [第一梯队-必练.md](./第一梯队-必练.md) 每周限时写 1 篇，写作时只从素材库取料
4. 有余力再推进 [第二梯队-选练.md](./第二梯队-选练.md) 的 P0 题目
5. 考前 1 周通读 [第三梯队-了解即可.md](./第三梯队-了解即可.md)
