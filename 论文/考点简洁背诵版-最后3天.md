## 〇、固定框架（背一套，所有考题通用）

**1. 统一摘要背景（开场必背，照念）**

**2. 项目概述（接背景，照念）**

**3. 平台总体架构（五层 + AI 能力层，背关键词）**
- 感知层：采集预处理多波段光谱
- 边缘 AI 层：**TensorFlow Lite** 本地推理/异常预判

- 应用层：可视化大屏 + 移动告警
- **AI 能力层（叠加）**：RAG 知识服务层 + 多智能体编排层（监测/分析/处置 Agent）+ LLMOps/AIOps 双中台

**4. 统一口径（数字锁死，勿现场编）**
端侧推理 < 500ms｜模型压缩 ~75%｜云端告警 P99 < 3s｜弱网视图 < 10s｜可用度 99.9%｜设备在线率 > 99%｜MTTR < 30min｜识别准确率 93%｜RAG 准确率 91%/幻觉 < 3%｜2025 年 9 月 120 点位全量上线。

## 一、架构风格的选择与应用（题1）

**要回应**：①简述项目与职责 ②说明选用的架构风格、组成/特点/适用场景 ③如何选+组合、遇问题怎么解决
**得分点**：
1. 列举主流风格及适用：分层（易改但耦合）、事件驱动（松耦合但缺统一视图）、微服务（独立部署但治理要求高）、管道-过滤器（批量转换）、仓库/黑板（智能决策）、闭环控制（感知-决策-执行）
2. 选型对比：排除纯单体（扩展失效）、纯事件驱动（无统一视图）、纯云端微服务（带宽炸/断网瞎）→ 选**混合架构**
3. 组合落地：感知层**闭环控制**、边缘内嵌**仓库风格**、通信**事件驱动**、云端**微服务分层**，按数据归属划边界
4. 问题两例（五段式）：断网丢数据→边缘 SQLite 落盘+断点续传；调用链复杂→**SkyWalking** 全链路追踪
**关键数字**：端侧 < 500ms、可用度 99.9%、视图延迟 < 10s

**得分点**：

## 四、领域驱动设计 DDD（题4）

**要回应**：①复杂项目与职责 ②战略+战术设计（限界上下文/聚合根/领域事件/通用语言） ③如何划边界、落地模型、解问题
**得分点**：
1. 战略：子域（核心/支撑/通用）→ 限界上下文锁边界 → 上下文映射通信
2. 战术：聚合（必须一起变动的对象圈起来）+ 聚合根（唯一入口保不变量）+ 领域事件（跨服务解耦）+ 通用语言

4. 落地：以"告警单"为聚合根；领域事件"告警发生/确认/升级"；全程通用语言
5. 问题两例：过度设计→按不变量拆聚合、对外精简；映射缺失→加防腐层收口

## 五、云边协同架构在端侧 AI 中的应用（题5 = AI 章节 D，骨架同）

**得分点**：

4. 问题两例：算力不足→定宽 IPU 算子+INT8+按需加载；下发难→**多队列灰度 + 断点续传 + 增量包**
**关键数字**：< 500ms、压缩 75%、零丢失、准确率 93%

## 六、实时流处理架构 Lambda（题6）

**要回应**：①实时项目与职责 ②主流流处理原理 + Lambda 优缺点 ③落地解乱序/冲击/状态一致性
**得分点**：
1. Lambda 原理：批处理层（全量稳）+ 速度层（低延迟补增量）+ 服务层（合并）；优点=实时离线各自演进可对账，缺点=双份代码/口径维护
2. 选型对比：仅 Spark（延迟分钟级不行）/ 仅 Flink（长期报表不稳）/ Lambda（选定）
3. 落地：实时=Flink 滑动窗口秒级告警；离线=Spark 全量趋势；服务层按"设备+点位+时间+指标"主键对账
4. 问题三例：乱序→**watermark + 迟到容忍**；洪峰→**背压 + 并行度/分区优化 + 资源隔离**；状态→**checkpoint + 两阶段提交 + 幂等落库（Exactly-once）**
**关键数字**：P99 < 3s、峰值吞吐 2800/s、对账一致率 > 99.5%
