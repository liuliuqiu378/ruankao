## 🎯 一句话定位

案例分析题考察你**运用所学知识解决实际问题的能力**：基于一个具体项目背景，分析问题、提出方案、评估可行性与优缺点。

> 核心不是"找标准答案"，而是 **思维过程、决策依据、技术表达的完整性**。

---

## 📊 一、考什么？

共 5 道题：**第 1 题必答（25 分）+ 第 2~5 题选答（四选二，每题 25 分）**，完成 3 题，满分 75，45 分及格。

| 题型 | 性质 | 核心考点 |
|------|------|----------|
| 1. 架构基础与风格 | **必做** | 架构风格、质量属性、架构评估（ATAM） |
| 2. 软件工程综合 | 选做 | 过程模型、需求工程、系统设计、测试策略 |
| 3. 数据库与数据设计 | 选做 | 数据库设计、NoSQL、缓存、分布式事务 |
| 4. 系统集成与架构 | 选做 | 微服务、ESB、中间件、Web 架构 |
| 5. 嵌入式与前沿技术 | 选做 | 嵌入式、AI/大数据、IoT、云原生 |

> ⚠️ **2026 新大纲提示**：AI 相关内容占比显著上升（约 25%），新增「AI 系统架构设计」「大模型部署策略」「智能系统性能优化」三个专题，质量属性常与 AI 需求（推理延迟、模型准确率、可解释性）结合出题。

详细考点与提问方式见 👉 [01-考题分析.md](./01-考题分析.md)

## 🧩 二、怎么考？

- **考试时间**：90 分钟（与综合知识连考，总时长 240 分钟，案例部分独立计时）
- **作答方式**：机考主观题，文字输入，可能需绘制简单架构图 / 流程图 / 时序图
- **评分逻辑**：关注**思路、依据、逻辑性**，而非死记硬背的术语

四大评分维度与常见失分点：

| 维度 | 核心要求 | 常见失分点 |
|------|----------|------------|
| 问题分析与定位 | 准确识别核心矛盾 / 瓶颈 / 风险 | 泛泛而谈，未抓关键 |
| 解决方案设计 | 针对性强、可行、全面、体现权衡 | 方案不切实际，缺优缺点分析 |
| 技术论证与阐述 | 逻辑清晰、术语准确、说明理由 | 论证混乱、口语化、理由缺失 |
| 规范与完整性 | 有问必答、结构完整、语言精炼 | 漏题、冗长、常识性错误 |

详细方法论见 👉 [02-答题方法论.md](./02-答题方法论.md)

## 🧠 三、如何记忆？

死记硬背绝非上策，关键在于 **理解、关联、结构化**：

1. **构建知识框架，理解优先**：按"架构风格 / 质量属性 / 技术领域"三条主线建立体系，而非零散记忆。
2. **善用口诀与对比**：ATAM 步骤、七大质量属性、五种架构风格等精确内容，用口诀、对比表、思维导图巧记。
3. **理论与项目结合**：把理论代入你参与过或了解的项目场景，思考"这个理论在那项目中怎么体现？换方案会怎样？"

知识框架图谱见 👉 [03-知识图谱.md](./03-知识图谱.md)

## 🚀 四、如何高效准备？

建议 **10 周三阶段**：基础（1-4 周）→ 强化（5-8 周）→ 冲刺（9-10 周）。

- **资料**：第 2 版官方教程 + 近 5 年真题（最重要）+ 系统课程 + 自整思维导图
- **时间分配**：必做题 35-40 分钟，选做题各 25-30 分钟
- **答题步骤**：审题(5min) → 构思(5-10min) → 作答(15-20min) → 检查(2min)
- **表达技巧**：结构化（总-分）、关键词凸显、量化具体化、体现权衡反思
- **机考注意**：平时就在电脑上练，熟悉绘图与输入

详细计划与清单见 👉 [04-备考计划.md](./04-备考计划.md)

## 💎 总结

案例题是知识、思维、耐力的综合考验——不只考"知道什么"，更考"如何思考、如何解决问题"。

- **核心在理解**：架构背后的权衡、设计原则、质量属性
- **关键在练习**：真题是最好的老师，形成答题套路
- **重点在应用**：理论始终与项目场景结合
- **成事在坚持**：每次专注学习都离目标更近
