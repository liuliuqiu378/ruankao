# 一、全书易混概念对比表

> 💡 **用法建议**：先看**左列**想一秒"它俩到底差在哪"，再看右列验证。**主动回忆比被动阅读有效 3 倍。**

## 1.1 操作系统

| 对比项 | A | B | 关键区别 |
|--------|---|---|---------|
| **进程 vs 线程** | 资源分配的**基本单位** | CPU 调度的**基本单位** | 进程独立地址空间，线程共享 |
| **同步 vs 互斥** | 协作（直接制约） | 竞争（间接制约） | 同步是"等你做完"，互斥是"轮流用" |
| **分页 vs 分段** | **物理**单位，**大小固定**，**用户不可见** | **逻辑**单位，**大小可变**，**用户可见** | 分页为提效，分段为共享/保护 |
| **内部碎片 vs 外部碎片** | 已分配但**没用上**（页内） | 未分配但**太小用不了**（分区间） | 分页有内部碎片，分段有外部碎片 |
| **硬链接 vs 软链接** | 多个目录项指向**同一 inode** | 内容是**目标文件路径** | 删源文件，硬链接仍有效，软链接失效 |
| **程序查询 vs 中断 vs DMA** | CPU 全程等 | 传完一个**字**通知一次 | **传完一整块**才通知一次 |
| **死锁预防 vs 避免** | 破坏四个必要条件之一 | **银行家算法**试算 | 预防是"事前规则"，避免是"每次判断" |

## 1.2 计算机网络

| 对比项 | A | B | 关键区别 |
|--------|---|---|---------|
| **TCP vs UDP** | 面向连接、可靠、慢 | 无连接、不可靠、快 | TCP 有三次握手与重传 |
| **401 vs 403** | **未认证**（没登录） | **已认证但无权限** | 401 是"你是谁"，403 是"你不能" |
| **502 vs 504** | 网关收到**无效响应** | 网关**等待超时** | 502"回了但不对"，504"没回" |
| **301 vs 302** | **永久**重定向 | **临时**重定向 | 301 会被浏览器缓存 |
| **交换机 vs 路由器** | 数据链路层，按 **MAC** | 网络层，按 **IP** | 交换机**不能**隔离广播域，路由器**能** |
| **冲突域 vs 广播域** |  Hub 全部共享 | Hub/Switch 全部共享 | 路由器**每个端口**一个广播域 |
| **ARP vs RARP** | IP → **MAC** | MAC → **IP** | 方向相反 |
| **IPv4 vs IPv6** | **32 位**，点分十进制 | **128 位**，冒号十六进制 | — |
| **RIP vs OSPF** | **距离矢量**，跳数≤15 | **链路状态**，Dijkstra | OSPF 收敛快、适合大型网络 |
| **IGP vs EGP** | 自治系统**内部**（RIP/OSPF） | 自治系统**之间**（**BGP**） | — |

## 1.3 数据库

| 对比项 | A | B | 关键区别 |
|--------|---|---|---------|
| **逻辑独立性 vs 物理独立性** | 由**外模式/模式映像**保证 | 由**模式/内模式映像**保证 | "外→逻辑，内→物理" |
| **2NF vs 3NF** | 消除**部分**函数依赖 | 消除**传递**函数依赖 | 逐级递进 |
| **不可重复读 vs 幻读** | 同一行**内容**变了 | 符合条���的**行数**变了 | UPDATE vs INSERT |
| **X 锁 vs S 锁** | 排他/写锁，独占 | 共享/读锁，可共存 | X 与任何锁都不相容 |
| **一级/二级/三级封锁协议** | 防丢失更新 | +防读脏 | +防不可重复读 |
| **B 树 vs B+ 树** | 关键字**所有节点**都存 | 关键字**只在叶子**，叶子**链表相连** | B+ 树**范围查询快** |
| **规范化 vs 反规范化** | 减少冗余，Join 多 | 增加冗余，**查询快** | 反规范化是**空间换时间** |
| **增量 vs 差异备份** | 基于**上次任何备份** | 基于**上次完全备份** | 差异恢复快于增量 |
| **σ vs π** | **选择**（筛**行**） | **投影**（筛**列**） | σ 像竖线→行，π 上横→列 |

## 1.4 数据结构与算法

| 对比项 | A | B | 关键区别 |
|--------|---|---|---------|
| **顺序表 vs 链表** | **随机存取**，插入删除 O(n) | 顺序存取，插入删除 **O(1)** | 顺序表存储密度高 |
| **栈 vs 队列** | **LIFO** 后进先出 | **FIFO** 先进先出 | 栈用函数调用，队列用缓冲区 |
| **DFS vs BFS** | 用**栈**（递归） | 用**队列** | — |
| **Prim vs Kruskal** | 适合**稠密**图（O(n²)） | 适合**稀疏**图（O(e log e)） | 都是求最小生成树（**贪心**） |
| **Dijkstra vs Floyd** | **单源**最短路径 | **任意两点**最短路径 | Floyd 是**动态规划** |
| **贪心 vs 动态规划** | 每步选最优，**不能回退** | 保存子问题解，**可回退** | **0-1 背包只能用 DP** |
| **稳定 vs 不稳定排序** | 插/泡/归/基 | 快/选/堆/希 | 口诀：**"插泡归基"** |
| **满二叉树 vs 完全二叉树** | 每层都满 | 按层序与满二叉树**一一对应** | 满 ⊆ 完全 |

## 1.7 分布式与新技术

| 对比项 | A | B | 关键区别 |
|--------|---|---|---------|
| **CP vs AP** | 保一致性，**牺牲可用性** | 保可用性，**牺牲强一致** | **P 必选**，只能二选一 |
| **ZooKeeper vs Eureka** | **CP** | **AP** | Nacos 两者都支持 |
| **ACID vs BASE** | **强一致**，传统事务 | **最终一致**，分布式 | BASE = CAP 中 AP 的延伸 |
| **2PC vs TCC** | 强一致，**资源锁定、阻塞** | 最终一致，**业务侵入大** | TCC 要写 Try/Confirm/Cancel |
| **TCC vs Saga** | 预留资源，**性能好** | **长事务**，靠**补偿**回滚 | Saga 无隔离性 |
| **Paxos vs Raft** | 经典但**难实现** | **易理解**（选举+日志复制+安全） | etcd 用 Raft，ZooKeeper 用 ZAB |
| **缓存穿透 vs 击穿 vs 雪崩** | 查**不存在**的 key | **单个热点** key 过期 | **大批** key 同时过期/集群宕机 |
| **Kafka vs RabbitMQ** | **高吞吐**（百万级） | **低延迟**、路由灵活 | RocketMQ 有事务消息 |
| **容器 vs 虚拟机** | 共享宿主**内核**，轻量秒启 | 独立 **Guest OS**，重、隔离强 | — |
| **Lambda vs Kappa** | **三层**（批+速度+服务） | **两层**（只有流，靠**重放**） | Lambda 维护两套代码 |
| **Flink vs Spark Streaming** | **真流式**（逐条） | **微批**（准实时） | Flink 用 Watermark 处理乱序 |
| **星型 vs 雪花模型** | 维表**未规范化**，**查询快** | 维表**规范化**，省空间 | 星型最常用 |
| **数据湖 vs 数仓** | **Schema-on-Read**（原始多格式） | **Schema-on-Write**（已建模） | 湖仓一体 = Lakehouse |
| **RAG vs 微调** | **外挂知识库**，改知识 | **改模型参数**，改行为 | "改知识→RAG，改风格→微调" |
| **PoW vs PoS vs PBFT** | **算力竞赛**，能耗高 | **权益**，节能 | **联盟链**用 PBFT，容忍 1/3 恶意 |
| **RBAC vs ABAC** | 静态，基于**角色** | 动态，基于**属性**（细粒度） | ABAC 是零信任基础 |
| **对称 vs 非对称 vs 摘要** | 同密钥，**可逆**，快 | 公私钥，**可逆**，慢 | 摘要**不可逆** |
| **数字签名 vs 数字信封** | 私钥加密**摘要** → 完整性+不可否认 | 对称加密数据+公钥加密对称密钥 | 前者防伪，后者兼顾速度 |

# 四、"最 / 唯一 / 第一" 类考点

> 🎯 **命题人最爱在"最""唯一""第一""标志"上做文章。** 把这些单独拎出来背，性价比极高。

| 考点 | 答案 |
|------|------|
| **最小的资源分配单位** | **进程** |
| **最小的 CPU 调度单位** | **线程** |
| **进程存在的唯一标志** | **PCB（进程控制块）** |
| **I/O 方式中 CPU 干预最少 / 效率最高** | **通道**（其次 DMA） |
| **DMA 传输的基本单位** | **数据块**（中断方式是"字"） |
| **唯一没有保护期限的知识产权** | **商业秘密** |
| **唯一"自动产生"的知识产权** | **著作权**（创作完成即享有） |
| **必须由多国/主管部门审批才取得的知识产权** | 专利权（申请+审批）、商标权（注册）、布图设计（登记） |
| **最早的架构评估方法** | **SAAM** |
| **唯一会产生 Belady 异常的置换算法** | **FIFO**（LRU、OPT 不会） |
| **理论上最优但无法实现的置换算法** | **OPT** |
| **确定二叉树必须具备的遍历** | **中序遍历**（前序+后序不能唯一确定） |
| **最弱 / 最强的白盒覆盖** | **语句覆盖（最弱） / 路径覆盖（最强）** |
| **占比最大的软件维护类型** | **完善性维护**（50%~66%） |
| **平均最快但不稳定的排序** | **快速排序**（有序时退化到 O(n²)） |
| **唯一不可能漏判的数据结构** | **布隆过滤器**（有误判无漏判） |
| **K8s 最小的调度/部署单元** | **Pod** |
| **最主流（事实标准）的架构评估方法** | **ATAM** |
| **唯一能隔离广播域的常用网络设备** | **路由器** |
| **软件著作权保护期限中"永久保护"的权利** | 署名权、修改权、保护作品完整权 |
| **最短路径（单源）算法** | **Dijkstra**（贪心） |
| **任意两点最短路径算法** | **Floyd**（动态规划） |
| **唯一既保证一致性又属于"传统事务"的模型** | **ACID** |
| **面向对象设计的最高目标/原则** | **开闭原则（OCP）** |
| **关键路径是网络图中最长还是最短的路径** | **最长**（决定最短工期） |
| **等保 2.0 中多数企业系统的定级目标** | **第三级（监督保护级）** |
