## 🎯 理论知识一句话定位

理论知识是案例与论文的"地基"——综合知识科目（75 道选择题）直接考查，案例与论文中的技术论证也依赖于此。**理解原理 + 建立对比 + 口诀速记**是高效掌握的关键。
