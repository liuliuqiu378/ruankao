# 00 · 新手使用指南 — 先读这份，再开始学

> **这份文档解决什么问题**：你已经有一堆资料，但不知道**从哪开始、每天学多少、学了怎么不忘**。
> 本篇只讲**方法**，不讲知识点。读完 10 分钟，能省你 20 小时的无效努力。

---

## 一、先纠正三个错误认知

### ❌ 错误认知 1：「我要把教程全部看完」

**真相**：系统架构设计师教程 800+ 页，全覆盖需要 300+ 小时。而及格只需要 45 分（**60% 的正确率**）。
> ✅ **正确做法**：按 [README 的分值大盘](./README.md#二综合知识考情速览决定你的时间投向)，**先拿下产出最高的 60%**，剩下的随缘。
> 你不需要 100 分，你需要**稳定 50 分**。

### ❌ 错误认知 2：「看懂了就是会了」

**真相**：综合知识是**识别型**考试（四选一），不是**回忆型**考试（填空）。
"看懂"只需要被动理解，"会做"需要**看到题干 3 秒内调出知识点**。这是两种完全不同的能力。
> ✅ **正确做法**：每学完一节，**立刻做 5~10 道对应真题**。做不出来 = 没学会，回去再看。

### ❌ 错误认知 3：「我英语不好，最后 5 题放弃」

**真相**：这 5 题的瓶颈是**技术术语量**，不是英语水平。而且它每年固定 5 题、主题收敛。
> ✅ **正确做法**：花 6~8 小时过一遍 [08-英语题专项](./08-英语题专项.md)，稳定拿 3~4 分。

## 三、四步学习法（每个知识点都这么走）

```
┌─────────────────────────────────────────────────────────┐
│  第 1 步  预 览（2 分钟）                                │
│     扫一眼本章的表格和小标题，知道"要学几个东西"         │
│     → 目的：给大脑一个"文件柜"，后面往里放东西           │
├─────────────────────────────────────────────────────────┤
│  第 2 步  理 解（10 分钟）                               │
│     只读「直觉/比喻」部分，确保能用大白话复述出来        │
│     → 自检：能不能给一个不懂的人讲明白？讲不明白就重看    │
├─────────────────────────────────────────────────────────┤
│  第 3 步  编 码（5 分钟）★最关键★                       │
│     把知识压缩成「口诀 / 对比表 / 数字」三种形式之一     │
│     → 作用：把"理解"变成"考场上 3 秒能调出来的东西"      │
├─────────────────────────────────────────────────────────┤
│  第 4 步  检 索（5 分钟）                                │
│     合上文档，做 5 道真题。做错 → 回到第 2 步            │
│     → 作用：验证"编码"是否成功                           │
└─────────────────────────────────────────────────────────┘
```

> 🔑 **第 3 步「编码」是大多数人跳过的一步，也是拉开差距的一步。**
> 看懂了 ≠ 记住了。你必须主动把它压成一句口诀、一张对比表、或一组数字。

## 四、五种记忆法（本书编写依据，你也照这个记）

### 方法 1：比喻法 —— 对付抽象概念

任何抽象概念，先找一个生活对应物。

| 抽象概念 | 生活比喻 |
|----------|---------|
| 进程 vs 线程 | **一栋楼 vs 楼里的房间**：楼有独立地址（进程），房间共享楼的地址（线程共享地址空间） |
| 同步 vs 异步 | **打电话 vs 发微信**：打电话必须等对方接（阻塞），发微信发完就干别的（非阻塞） |
| 阻塞 vs 非阻塞 | **排队点餐 vs 取号去逛街**：前者干等，后者拿到号可以先走 |
| 耦合 vs 内聚 | **夫妻 vs 家人**：两家人越少来往越好（低耦合），一家人越团结越好（高内聚） |
| 管道-过滤器 | **工厂流水线**：每个工位只干一件事，干完往下传 |
| 事件驱动 | **小区广播喇叭**：喊的人根本不知道谁会响应 |
| 代理模式 | **明星的经纪人**：想找明星先过经纪人这关（控制访问） |

### 方法 2：对比法 —— 对付易混概念

**孤立的概念记不住，成对的记得住。** 本书所有易混点都做成了双列对比表，见 [06-理论速记与对比表.md](./06-理论速记与对比表.md)。

使用时：**先自己想一遍"这俩到底差在哪"**，再看表，印象深一倍。

### 方法 3：口诀法 —— 对付"必须精确回忆"的内容

适合：步骤类（ATAM 九步）、分类类（OSI 七层）、清单类（质量属性战术）。

**编口诀的原则**：
1. **首字串联**最好用：OSI 七层 → "**物**链**网**传**会**表**应**"（从下往上）→ 谐音"**巫联网传会镖瘾**"
2. **越荒诞越好记**：夸张、有画面感的口诀比工整的更容易提取。
3. **自己编的 > 别人编的**：自己编的过程就是一次深度加工。

### 方法 4：数字归类法 —— 对付"数字型"考点

把零散数字**归拢到一处**集中记。例如：

| 数字 | 含义 |
|------|------|
| **1024** | 存储换算（1KB = 1024B） |
| **1000** | 带宽换算（1kbps = 1000bps） |
| **-1** | 补码下限：-2ⁿ⁻¹ |
| **-2** | 子网可用主机数：2^h - 2 |
| **+1** | McCabe：判定数 + 1 |

> 📌 见 [06 的「数字考点速查」](./06-理论速记与对比表.md#一数字考点速查)，把所有数字考点集中在一张表里。

### 方法 5：场景代入法 —— 对付"背了也不会用"的知识

> 每学一个技术，问自己三个问题：
> 1. **我工作中哪里见过它？**（没有就想象一个场景）
> 2. **如果不用它，会出什么问题？**
> 3. **它有什么代价？**（架构题的万能追问）

> 例：学"Redis 缓存穿透" → 想象"双十一有人恶意刷不存在的商品 ID，请求全部打到数据库"。
> 场景一建立，答案（布隆过滤器 / 空值缓存）就自然出来了，不用背。

## 五、错题本：提分最快的工具

### 模板（建议用表格，一行一题）

| 列 | 内容 | 示例 |
|----|------|------|
| 日期 | 做题日期 | 2026-09-04 |
| 题干关键词 | **只抄 10 个字**，不抄全题 | "流水线 4 段 100 条指令" |
| 我的答案 / 正确答案 | — | B / C |
| **错因归类** | 见下方四类 | **单位没换算** |
| 一句话笔记 | 以后怎么避免 | "见 Mbps 先 ÷8，见 ms 先换 s" |

### 错因只有四类（归类后你就知道该练什么）

| 错因 | 表现 | 对策 |
|------|------|------|
| ① **没记住** | "我知道有这个东西，但想不起来具体是啥" | → 回去做「编码」，编口诀/对比表 |
| ② **没理解** | "选项我都认识，但不知道选哪个" | → 回去看「直觉/比喻」部分 |
| ③ **看错/算错** | "我会，但单位没换 / 看漏了'不包括'" | → 建立**检查清单**（见下） |
| ④ **超纲** | "这词我压根没见过" | → 记入错题库，**别深挖**，性价比低 |

### 🔴 高频"看错"检查清单（考试时逐条默念）

- [ ] **单位统一了吗？**（ms / s，MB / Mb，分钟 / 小时）
- [ ] 题干有没有"**不包括**""**错误的是**""**除了**"？（每年都有人栽在这）
- [ ] 是"**可用主机数**"还是"**地址数**"？（一个 -2 一个不减）
- [ ] 是"**串行**"还是"**并行**"？是"**可靠性**"还是"**可用性**"？
- [ ] "**最多**"还是"**至少**"？"**平均**"还是"**最大**"？

## 六、真题怎么用（三遍法）

真题是**唯一**能直接反映命题人思路的材料。近 5 年真题至少做 3 遍，每遍目的不同：

| 遍数 | 时间 | 怎么做 | 目的 |
|:----:|------|--------|------|
| **第 1 遍** | 学完 60% 内容后 | **不限时，开卷**，可以查文档 | 熟悉题型与问法，建立"题感" |
| **第 2 遍** | 考前 3 周 | **限时模拟**（150 分钟做完 75 题） | 练速度与取舍 |
| **第 3 遍** | 考前 1 周 | **只做前两遍的错题** | 消灭个人盲区 |

> ⚠️ **不要**：把真题当模拟卷一路刷完就扔。
> ✅ **要**：每道题做完后问"**命题人想考我什么？干扰项是怎么设计的？**"

## 七、每日 / 每周节奏模板

### 工作日（每天 1 小时）

```
前  5 分钟：复习昨天的口诀/对比表（不复习 = 白学）
中 40 分钟：新内容（按四步学习法）
后 10 分钟：做 5 道对应真题
最  5 分钟：填错题本
```

### 周末（每次 2~3 小时）

```
1. 本周内容快速回扫（30 分钟）
2. 做 1 套真题的某一科，或半套综合知识（60 分钟）
3. 错题归因 + 回查文档（60 分钟）
```

## 八、六个常见误区（看看你中了几个）

| 误区 | 后果 | 正确做法 |
|------|------|---------|
| ① 通读教程不做题 | 看完就忘，考场上认不出 | 学 1 小时，做题至少 15 分钟 |
| ② 只做真题不看教材 | 遇到变体题就懵 | 真题 + 本目录文档配合 |
| ③ 死磕冷门难点 | 时间耗尽，高频分没拿到 | 按分值优先级，冷门直接放弃 |
| ④ 忽视英语题 | 白丢 3~4 分 | 花 6 小时过 [08](./08-英语题专项.md) |
| ⑤ 不建错题本 | 同一个坑掉两次 | 见第五节 |
| ⑥ 考前熬夜突击 | 案例和论文体力不支 | 考前 3 天只回顾，不学新东西 |

## 九、一份自检清单（每学完一章打勾）

```
□ 我能用大白话给别人讲明白这个概念吗？
□ 我能说出它和 XX 的区别吗？（找一个最像的概念对比）
□ 我给它编了口诀 / 画了对比表吗？
□ 我做对了 5 道对应真题吗？
□ 我知道这个知识点"命题人最爱怎么考"吗？
```

> 五项全勾，这一章才算过。**任何一项没勾，不要往下走。**
