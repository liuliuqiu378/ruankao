# 第 1 章 · 知识产权总览

## 1.1 五类知识产权对比（🔴 先背这张总表）

| 类型 | 保护对象 | 取得方式 | **保护期限** | 主管/依据 |
|------|---------|---------|:------------:|----------|
| **著作权** | 文学、艺术、科学作品（**含软件**） | **自动产生**（创作完成即享有，登记为自愿） | 自然人：**终生 + 死后 50 年**<br>法人：**首次发表后 50 年** | 《著作权法》《计算机软件保护条例》 |
| **专利权** | 发明、实用新型、外观设计 | **必须申请 + 审批** | **发明 20 年**<br>**实用新型 10 年**<br>**外观设计 15 年**（教材口径常写 10 年） | 《专利法》 |
| **商标权** | 商标（区分商品/服务来源） | **必须注册** | **10 年**（可无限续展，每次 10 年） | 《商标法》 |
| **商业秘密** | 技术信息、经营信息 | 自动（**须采取保密措施**） | **无期限**（保密多久保护多久） | 《反不正当竞争法》 |
| **集成电路布图设计** | 芯片的布图设计 | **必须登记** | **10 年** | 《集成电路布图设计保护条例》 |

> 🔴 **记忆口诀（最重要的一句）**：
> **"著作自动、专利要审、商标要注册、秘密靠保密、布图要登记"**

## 1.2 知识产权的特点

| 特点 | 说明 |
|------|------|
| **无形性** | 保护的是智力成果，不是物质载体（买一本书 ≠ 买到著作权） |
| **专有性（排他性）** | 未经许可不得使用 |
| **地域性** | 只在授权国家/地区有效（**中国专利在美国不受保护**） |
| **时间性** | 有保护期限，到期进入**公有领域**（**商业秘密除外**） |

> 🔴 **必背**：**知识产权的四性 = 无形性、专有性、地域性、时间性**。
> 其中**商业秘密不受"时间性"限制**（可永久保密）——这是常见陷阱。

# 第 2 章 · 著作权（含软件著作权）

## 2.1 著作权的"两类权利"

| 类别 | 内容 | 可否转让 | 保护期 |
|------|------|:--------:|--------|
| **人身权（精神权利）** | **发表权、署名权、修改权、保护作品完整权** | ❌ 不可转让 | **署名权、修改权、保护作品完整权：永久保护** |
| **财产权（经济权利）** | 复制权、发行权、出租权、展览权、表演权、信息网络传播权、改编权、翻译权等 | ✅ 可转让、可许可 | 有期限（50 年/终生+50 年） |

> 🔴 **必背**：**署名权、修改权、保护作品完整权 → 永久保护**（这是最高频的"特殊保护期"考点）。

## 2.2 保护期（🔴 必考）

| 情形 | 保护期 |
|------|--------|
| **自然人作品** | **作者终生 + 死亡后 50 年**，截止于死亡后**第 50 年的 12 月 31 日** |
| **合作作品** | 截止于**最后死亡**的作者死亡后第 50 年的 12 月 31 日 |
| **法人/非法人组织作品** | **首次发表后 50 年**；**创作完成后 50 年内未发表的，不再保护** |
| **职务作品**（著作权归法人的） | 同上（50 年） |
| **视听作品** | 发表后 50 年 |
| **匿名/假名作品** | 首次发表后 50 年（作者身份确定后按一般规则） |

> 🧠 **记忆**：**"自然人算'活'的（终生+50），法人算'死'的（首次发表后50）"**。

## 2.3 著作权归属（🔴 必考易混）

| 情形 | 归属规则 |
|------|---------|
| **一般作品** | 归**作者**（创作作品的自然人） |
| **职务作品（一般）** | 著作权归**作者**，单位在**业务范围内**有**优先使用权**（**2 年内**未经单位同意不得许可第三人以相同方式使用） |
| **职务作品（特殊）** | 主要利用**单位物质技术条件**创作，并由单位承担责任的（如**工程设计图、产品设计图、地图、计算机软件**等），**作者仅享有署名权**，其他权利归**单位** |
| **委托作品** | **有合同约定从约定**；**无约定 → 归受托人（受委托方）** |
| **合作作品** | 归**合作作者共同享有**；可分割使用的，作者对各自部分单独享有著作权 |
| **汇编作品** | 归**汇编人**，但不得侵犯原作品著作权 |
| **视听作品** | 归**制作者**（编剧、导演、摄影等作者享有署名权） |

> 🔴 **必背**：**委托开发，没有约定 → 著作权归"受托人/受委托方"**（不是委托人！这是最高频的坑）。

### 软件著作权的特殊规定（《计算机软件保护条例》）

| 要点 | 内容 |
|------|------|
| **产生时间** | 自**软件开发完成之日**起**自动产生**（**登记是自愿的**，登记只是"初步证明"） |
| **保护期限** | 自然人：**终生 + 死后 50 年**；法人：**首次发表后 50 年**（开发完成后 50 年内未发表不再保护） |
| **职务开发软件** | 在单位任职期间开发的软件，若是**执行本职工作的结果**（本职工作中明确指定的开发目标，或从事本职工作所预见/自然的结果）→ **著作权归单位** |
| **不保护什么** | **不保护开发软件所用的「思想、处理过程、操作方法、数学概念」**（只保护"表达"） |

> 🔴 **必背**：
> - **"只保护表达，不保护思想"**
> - **职务开发软件 → 归单位**（这是软件著作权与一般职务作品最大的不同）
> - **软件登记不是取得著作权的前提**（自动产生）

## 2.4 合理使用与法定许可

**合理使用**（**不经许可、不付报酬**，但须指明作者姓名、作品名称，且不得侵犯其他权利）：

| 情形 | 说明 |
|------|------|
| 个人学习、研究、欣赏 | 使用他人**已发表**的作品 |
| 适当引用 | 为介绍、评论、说明问题而**适当引用** |
| 新闻报道 | 不可避免地再现或引用 |
| 课堂教学、科学研究 | **少量复制**，**不得出版发行** |
| 国家机关执行公务 | 合理范围内使用 |
| 图书馆等陈列保存 | 为**保存版本**需要复制本馆收藏的作品 |
| 免费表演 | **不向公众收费、不向表演者支付报酬** |
| 公共场所艺术品临摹绘画摄影 | — |
| **翻译成少数民族文字**在国内出版 | — |
| **改成盲文出版** | — |

> 🔴 **必背**：合理使用的关键词是 **"非商业、少量、已发表、指明作者"**。
> ⚠️ **常见陷阱**：**"为了教学，把整本教材复印发给学生" → 不是合理使用**（超出了"少量"范围）。

**法定许可**（**不经许可，但要付报酬**）：教科书汇编、报刊转载、录音制作者使用已录制的音乐作品、广播电台电视台播放已发表作品等。

# 第 3 章 · 专利权

## 3.1 三种专利对比（🔴 必考）

| 类型 | 保护对象 | **期限** | 审查 | 创造性要求 |
|------|---------|:--------:|------|-----------|
| **发明** | 产品、方法或其改进的**新技术方案** | **20 年** | **实质审查**（3 年内提出） | 有**突出的**实质性特点和**显著的**进步 |
| **实用新型** | 产品的**形状、构造**或其结合的实用新技术方案（"小发明"） | **10 年** | **初步审查**（不实质审查） | 有实质性特点和进步 |
| **外观设计** | 产品的形状、图案、色彩或其结合的美感设计 | **15 年**<br>（2021 新法；教材常写 10 年） | 初步审查 | 不属于现有设计 |

> 🔴 **必背**：
> - **三种专利期限：20 / 10 / 15**（发明 20 最长，实用新型 10 最短）
> - **均自「申请日」起计算**（不是授权日、不是公告日）
> - ⚠️ **注意**：多数现行教材仍写**外观设计 10 年**（2021 年修订《专利法》改为 15 年）。**若选项同时出现 10 与 15，按当年教材/大纲口径选 10 年**；若只有 15 年则选 15。

## 3.2 授予专利权的条件

> **三性**：**新颖性 + 创造性 + 实用性**

| 特性 | 含义 |
|------|------|
| **新颖性** | 不属于**现有技术**；也没有**同样的**发明创造在申请日以前提出申请 |
| **创造性** | 与现有技术相比有**突出的实质性特点和显著的进步**（发明）/ 有实质性特点和进步（实用新型） |
| **实用性** | 能够**制造或使用**，并能产生**积极效果** |

## 3.3 不授予专利权的对象（🔴 必考）

| 不授予 | 说明 |
|--------|------|
| **科学发现** | 如发现一颗新星（发现 ≠ 发明） |
| **智力活动的规则和方法** | 如**数学方法、游戏规则、商业方法、计算方法**（🔴 **注意：这是软考高频考点！**） |
| **疾病的诊断和治疗方法** | 但**诊断治疗的仪器、药物**可授权 |
| **动物和植物品种** | 但其**生产方法**可授权 |
| **用原子核变换方法获得的物质** | — |
| **对平面印刷品的图案、色彩或其结合作出的主要起标识作用的设计** | — |
| **违反法律、社会公德、妨害公共利益**的发明创造 | 如**赌博工具**、克隆人的方法 |

> 🔴 **必背陷阱**：**"计算机程序本身"（纯算法、商业方法）= 不授予专利权**（属于智力活动规则）。
> 但**"计算机程序 + 硬件/技术方案"（如一种提高计算机运行效率的方法）可以授权**。
> 📌 这正是软考爱考的点：**软件本身受《著作权法》保护，不受《专利法》保护**。

## 3.4 专利的申请原则

- **先申请原则**：同样的发明创造，**授予最先申请的人**
- **同日申请**：协商；协商不成，**都驳回**（或授予最先完成的人）
- **单一性原则**：一件申请**一项发明**
- **优先权**：外国优先权（发明/实用新型 **12 个月**，外观设计 **6 个月**）；本国优先权 **12 个月**

# 第 4 章 · 商标权

| 要点 | 内容 |
|------|------|
| **取得** | **必须注册**（自愿注册，但**注册商标才有专用权**） |
| **有效期** | **10 年**，自**核准注册之日**起计算 |
| **续展** | 期满前 **12 个月**内办理续展；**可宽展 6 个月**；每次续展 **10 年**，**可无限续展** |
| **申请原则** | **申请在先**；同一天申请的，**使用在先** |
| **注册条件** | **显著性**（便于识别）、不得与他人在先权利冲突、不得使用禁用标志 |
| **驰名商标** | **跨类保护**（即使未注册，在同类商品上也受保护；注册的驰名商标可跨类保护） |
| **商标 vs 著作权** | 著作权**自动产生**；商标**必须注册**才有专用权 |

> 🔴 **必背**：
> - **10 年 + 自"核准注册之日"起 + 可无限续展**
> - **商标续展期：期满前 12 个月 + 宽展 6 个月**

# 第 5 章 · 商业秘密与集成电路布图设计

## 5.1 商业秘密

> **定义**：**不为公众所知悉**、能为权利人**带来经济利益**、具有**实用性**并经权利人**采取保密措施**的技术信息和经营信息。

| 三要件 | 内容 |
|--------|------|
| **秘密性** | 不为公众所知悉（**不能从公开渠道获得**） |
| **价值性** | 能为权利人带来**经济利益**、具有**实用性** |
| **保密性** | 权利人**采取了保密措施**（签保密协议、设权限、加密等）🔴 **最关键** |

> 🔴 **必背**：
> - **商业秘密没有保护期限**（只要保密，就一直受保护）→ **这是它与其他知识产权最大的区别**
> - **"反向工程"获取商业秘密 ≠ 侵犯商业秘密**（合法）
> - **客户名单、配方、工艺、算法** 都可能构成商业秘密
> - 侵犯商业秘密属于**不正当竞争行为**

## 5.2 集成电路布图设计

| 要点 | 内容 |
|------|------|
| **取得** | **必须登记**（向国家知识产权局） |
| **保护期** | **10 年** |
| **起算** | 自**登记申请日**或**在世界任何地方首次投入商业利用之日**起，**以较前的日期为准** |
| **保护内容** | 布图设计本身 + 含有该布图设计的集成电路 + 含有该集成电路的物品 |

> 🔴 **必背**：**布图设计 10 年，起算以"较前日期"为准**（登记申请日 vs 首次商业利用日）。

## 5.3 不正当竞争行为（《反不正当竞争法》）

| 类型 | 例子 |
|------|------|
| **混淆行为** | 擅自使用他人有一定影响的商品名称、包装、装潢、企业名称、域名主体部分等 |
| **商业贿赂** | 回扣、贿赂 |
| **虚假宣传** | 虚假或引人误解的商业宣传 |
| **侵犯商业秘密** | 盗窃、贿赂、欺诈、电子侵入等手段获取 |
| **违法有奖销售** | 抽奖式有奖销售最高奖金额超过 **5 万元** |
| **商业诋毁** | 编造、传播虚假信息损害竞争对手商誉 |
| **互联网不正当竞争** | 未经同意插入链接、强制目标跳转、误导用户关闭/卸载他人合法产品、**恶意不兼容** |

# 第 6 章 · 标准化

## 6.1 标准体系（五级两类）

| 层级 | 制定主体 | 性质 | 说明 |
|------|---------|------|------|
| **国家标准** | 国务院标准化行政主管部门 | 分**强制性**和**推荐性** | **强制性标准必须执行**；推荐性自愿采用 |
| **行业标准** | 国务院有关行政主管部门 | **推荐性**（法律另有规定除外） | 国家标准的补充，**国标发布后行标即行废止** |
| **地方标准** | 省级标准化行政主管部门 | **推荐性** | 满足地方自然条件、风俗习惯 |
| **团体标准** | 社会团体（学会、协会等） | 自愿采用 | 供社会**自愿采用** |
| **企业标准** | 企业自行制定 | 自我声明公开 | 企业**可以**制定严于国标/行标的企业标准 |

> 🔴 **必背**：
> - **只有国家标准分强制性和推荐性**；行业标准、地方标准**是推荐性标准**
> - **强制性标准必须执行；推荐性标准自愿采用**
> - **国家鼓励采用推荐性标准**
> - **企业标准可以严于国家标准**（"严于"是允许的、受鼓励的）

## 6.2 标准代号（🔴 必考）

| 代号 | 含义 |
|------|------|
| **GB** | **强制性国家标准** |
| **GB/T** | **推荐性国家标准**（T = 推荐"推"的拼音首字母） |
| **GB/Z** | **国家标准化指导性技术文件**（Z = 指导"指"） |
| **DB + 行政区划代码** | 地方标准（如 **DB11** = 北京；**DB11/T** 为推荐性地方标准） |
| **T/ + 团体代号** | 团体标准（如 **T/CESA**） |
| **Q/ + 企业代号** | 企业标准 |

### 常见行业标准代号（记 8 个高频的）

| 代号 | 行业 | | 代号 | 行业 |
|:----:|------|-|:----:|------|
| **SJ** | 电子 | | **JB** | 机械 |
| **YD** | 通信 | | **DL** | 电力 |
| **GA** | 公共安全 | | **NY** | 农业 |

| **QJ** | 航天 | | **AQ** | 安全生产 |
| **HB** | 航空 | | **CB** | 船舶 |

> 🧠 **记忆**：**"SJ 电子、YD 通信、GA 公安、JR 金融"** —— 前四个最高频。

## 6.3 国际与国外标准组织

| 组织 | 全称 | 领域 |
|------|------|------|
| **ISO** | **国际标准化组织** | 综合性（除电工电子外） |
| **IEC** | **国际电工委员会** | 电工、电子 |
| **ITU** | **国际电信联盟** | 电信、无线电 |
| **IEEE** | 电气电子工程师学会 | 电气、计算机（如 **IEEE 802.3 以太网**、IEEE 754 浮点） |
| **IETF** | 互联网工程任务组 | 互联网标准（**RFC 文档**） |
| **W3C** | 万维网联盟 | Web 标准（HTML、CSS、XML） |
| **ECMA** | 欧洲计算机制造商协会 | 如 **ECMAScript（JavaScript 标准）** |

# 第 7 章 · 安全法规与密码

## 7.1 四大法规（🔴 必考时间与对象）

| 法规 | 施行时间 | 核心内容 |
|------|---------|---------|
| **《网络安全法》** | **2017.6.1** | 网络**安全等级保护制度**（核心制度）、关键信息基础设施保护、个人信息保护原则、网络运营者安全义务 |
| **《密码法》** | **2020.1.1** | 密码分类：**核心密码、普通密码、商用密码** |
| **《数据安全法》** | **2021.9.1** | **数据分类分级保护**、重要数据目录、数据安全风险评估、**数据出境安全管理**、数据安全审查 |
| **《个人信息保护法》** | **2021.11.1** | 个人信息处理规则（**合法、正当、必要、诚信**）、**敏感个人信息需"单独同意"**、跨境提供规则、个人权利 |

> 🔴 **必背时序**：**2017 网安法 → 2020 密码法 → 2021 数安法（9月）+ 个保法（11月）**
> 口诀：**"一七网络，二零密码，二一双法（数据安全法、个人信息保护法）"**

## 7.2 《密码法》三大密码分类（🔴 必考）

| 类别 | 用途 | 性质 |
|------|------|------|
| **核心密码** | 保护**国家秘密信息**（**绝密/机密级**） | **属于国家秘密**，实行严格统一管理 |
| **普通密码** | 保护国家秘密信息（**秘密级**） | **属于国家秘密** |
| **商用密码** | 保护**不属于国家秘密**的信息 | 公民、法人、其他组织**可依法使用** |

> 🔴 **必背**：**核心密码、普通密码属于国家秘密**；**商用密码不属于国家秘密**，用于保护一般信息。

## 7.3 国密算法（🔴 必考，常与信创结合）

| 算法 | 类型 | 对标国际算法 | 说明 |
|------|------|-------------|------|
| **SM1** | 对称（分组） | ≈ AES | **算法未公开**，以 IP 核形式存在于芯片中 |
| **SM2** | **非对称**（椭圆曲线 ECC） | ≈ **RSA** | 用于**数字签名、密钥交换、公钥加密** |
| **SM3** | **摘要（哈希）** | ≈ **SHA-256** | 输出 **256 位** |
| **SM4** | **对称（分组）** | ≈ **AES** | 分组/密钥长度均 **128 位** |
| **SM7** | 对称 | — | 适用于非接触式 IC 卡 |
| **SM9** | **标识密码（IBC）** | ≈ 基于身份的加密 | **无需证书**，用身份标识（如邮箱）作公钥 |
| **ZUC（祖冲之）** | 序列密码 | — | 4G/5G 移动通信加密 |

> 🔴 **必背（最高频）**：**SM2 = 非对称（替 RSA）；SM3 = 摘要（替 SHA-256）；SM4 = 对称（替 AES）**
> 口诀：**"2 非 3 摘 4 对称"**（二非三摘四对称）

## 7.4 等保 2.0（详见 [04 第 9.6 节](./04-分布式与新技术.md#96-等级保护-20-必考)）

| 要素 | 内容 |
|------|------|
| 核心标准 | **GB/T 22239-2019** |
| 五个等级 | 第一级（自主保护）→ 第二级（指导保护）→ 第三级（监督保护）→ 第四级（强制保护）→ 第五级（专控保护） |
| 架构 | **"一个中心，三重防护"**：安全管理中心 + 安全计算环境 + 安全区域边界 + 安全通信网络 |
| 新增对象 | 云计算、移动互联、物联网、工业控制系统、大数据 |

## 7.5 个人信息处理要点

| 要点 | 内容 |
|------|------|
| **处理原则** | **合法、正当、必要、诚信**；目的明确与**最小范围**；公开透明；保证质量；**安全保障** |
| **敏感个人信息** | **生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹**，以及**不满十四周岁未成年人**的个人信息 |
| **敏感信息处理** | 需取得个人的**单独同意**，并告知必要性与影响 |
| **个人权利** | **知情权、决定权、查阅复制权、更正补充权、删除权、可携带权、解释说明权** |
| **死者信息** | 死者个人信息按本法规保护（近亲属可行使相关权利） |

<details>
<summary>参考答案</summary>

1. **无形性、专有性、地域性、时间性**。其中**"时间性"对商业秘密不适用**（商业秘密只要保密就一直受保护）
2. **著作权：自动产生**（创作完成即享有）；**专利权：必须申请 + 审批**；**商标权：必须注册**
3. **作者终生 + 死亡后 50 年**，截止于死亡后**第 50 年的 12 月 31 日**
4. **署名权、修改权、保护作品完整权**
5. **归受托人（受委托方）**
6. **归单位**（《计算机软件保护条例》：执行本单位任务的开发，著作权由单位享有）
7. **只保护"表达"，不保护"思想、处理过程、操作方法、数学概念"**
8. **发明 20 年；实用新型 10 年；外观设计 15 年**（多数教材口径为 10 年）。**均自「申请日」起计算**
9. **不能**。因为《专利法》规定**"智力活动的规则和方法"不授予专利权**。软件本身受**《著作权法》**保护
10. **有效期 10 年，自核准注册之日起**；期满前 **12 个月**内续展，**宽展 6 个月**，每次续展 **10 年**，**可无限续展**
11. **秘密性**（不为公众所知悉）、**价值性**（能带来经济利益、具有实用性）、**保密性**（经权利人采取保密措施）
12. **没有**（无保护期限限制，保密多久保护多久）
13. **10 年**。自**登记申请日**或**在世界任何地方首次投入商业利用之日**起，**以较前的日期为准**
14. **强制性标准和推荐性标准**。行业标准**是推荐性标准**（法律另有规定除外）
15. **GB/T** = 推荐性国家标准；**GB/Z** = 国家标准化指导性技术文件；**DB11/T** = 北京市推荐性地方标准；**Q/ABC** = 某企业标准
16. **IDT（等同采用）、MOD（修改采用）、NEQ（非等效）**
17. 《网络安全法》**2017.6.1**；《密码法》**2020.1.1**；《数据安全法》**2021.9.1**；《个人信息保护法》**2021.11.1**
18. **核心密码、普通密码、商用密码**。其中**核心密码和普通密码属于国家秘密**
19. **SM2 = 非对称（对标 RSA，基于 ECC）**；**SM3 = 摘要/哈希（对标 SHA-256，输出 256 位）**；**SM4 = 对称（对标 AES，128 位）**
20. **一个中心 = 安全管理中心**；**三重防护 = 安全计算环境 + 安全区域边界 + 安全通信网络**
